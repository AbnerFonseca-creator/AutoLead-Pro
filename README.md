# AutoLead Pro - AI Prospector 🚀

Um software desktop SaaS B2B desenvolvido para otimizar a prospecção de leads geolocalizados. A ferramenta combina mapeamento interativo, extração de dados e inteligência artificial para gerar roteiros de vendas personalizados e automatizar o fluxo de contato com clientes em potencial.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.12.8
* **Interface Gráfica:** CustomTkinter / TkinterMapView
* **Bancos de Dados:** SQLite
* **Integrações (APIs):** Overpass API (OpenStreetMap), Google Gemini 2.5 API
* **Segurança:** Criptografia AES (biblioteca `cryptography`)
* **Manipulação de Dados:** Pandas (.xlsx), python-docx

## ✨ Funcionalidades
* **Mapeamento Interativo:** Visualização de leads em um mapa em modo escuro com sistema de cache dinâmico.
* **Extração de Dados:** Coleta de informações comerciais geolocalizadas via Overpass API.
* **Inteligência Artificial:** Geração de scripts de vendas personalizados e automáticos através da API do Gemini 2.5.
* **Sistema Híbrido:** Alternância fluida entre mensagens geradas por IA e elaboração manual.
* **Segurança Avançada:** Persistência de chaves de API e URLs com criptografia local, armazenadas de forma segura no ambiente do sistema operacional.
* **Conectividade:** Integração via Webhooks para disparo de dados a sistemas externos de CRM ou automação de marketing.
* **Geração de Relatórios:** Exportação do histórico de prospecção em formatos de planilha e texto.
